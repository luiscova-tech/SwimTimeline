What's on a card?

Each card is one session: event number, event name (gender kept, stroke abbreviated), heat count, and start time, with the session's start time and estimated finish in the header. When every event in a session shares one age group, it's stated once in the header instead of on every row; when a session mixes age groups, each row carries a short tag (11&U, 10-11, 11yo).
